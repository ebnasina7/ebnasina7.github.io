# Ebna Sina · Portfolio

Personal site of Ebna Sina, data science master's student in Berlin. Live at https://ebnasina7.github.io

Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages from `main`.

- `assets/images/stories/`: photos for the optional stories, resized with metadata removed. Captions live in `script.js`.
- `assets/data/scout.json`: per-player aggregates for the FootScout game, built by `tools/build_scout.py` from [StatsBomb Open Data](https://github.com/statsbomb/open-data). Raw events are not stored here.
